# Data Research Checklist — Gate Before Serious Modeling

## Historical coverage
- [ ] Mainboard IPO universe identified
- [ ] Date range documented
- [ ] issue/open/close/listing dates verified
- [ ] issue price and lot size verified
- [ ] listing outcome verified
- [ ] allotment/basis documents collected where available

## Subscription
- [ ] QIB history
- [ ] NII history
- [ ] Retail history
- [ ] total subscription
- [ ] timestamps/day-wise history
- [ ] source metadata

## GMP
- [ ] historical source identified
- [ ] historical coverage measured
- [ ] timestamps preserved
- [ ] cross-source disagreement measured
- [ ] missingness measured
- [ ] production licensing reviewed

## Fundamentals/valuation
- [ ] latest eligible financial snapshot for each decision timestamp
- [ ] peer methodology defined
- [ ] valuation calculations verified
- [ ] issue structure verified
- [ ] no future financial leakage

## Market
- [ ] Nifty history
- [ ] sector data
- [ ] volatility measure
- [ ] recent IPO performance

## Gate
Do not train the final model until completeness, leakage controls and limitations have been reviewed.
